GEARBRIDGE — BUILT-IN ITEM PHOTO REPLACEMENT GUIDE
==================================================

This folder contains every built-in/demo item image used by GearBridge.

HOW TO REPLACE A DEMO IMAGE WITH A REAL PHOTO
1. Take or download your real item photo.
2. Crop/resize it to 4:3 if possible (recommended: 1200 x 900 px).
3. Save it as JPG using EXACTLY the same filename shown below.
4. Replace the existing JPG file in this folder.
5. Do NOT change the database. GearBridge will show the replacement automatically.

Important: Keep the same filename and .jpg extension.
